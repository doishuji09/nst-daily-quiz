病態別栄養管理

肝硬変患者にみられる就寝前補食（LES：late evening snack）の目的として、正しいものはどれか。

答えと解説を見る
  1. 正解A. 早朝の飢餓状態（異化亢進）を防ぐため
  2. B. 腹水を減らすため
  3. C. 食道静脈瘤の破裂を防ぐため
  4. D. アンモニアの産生を増やすため

解説

肝硬変ではグリコーゲン貯蔵能が低下しており、一晩の絶食でも健常者の2〜3日の飢餓に相当する異化状態（脂肪・蛋白の分解）になる。そこで就寝前に 200 kcal 程度の補食（BCAA 製剤など）を摂る LES によって早朝の異化を抑え、栄養状態と QOL の改善が期待できる。1日のエネルギーを増やすのではなく、同じ量を分割して夜間の絶食時間を短くするのが要点である。
