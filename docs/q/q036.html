経腸栄養

経腸栄養剤の多くが「1 kcal/mL」を基準としているとき、1.5〜2.0 kcal/mL の高濃度栄養剤を選ぶ主な理由はどれか。

答えと解説を見る
  1. 正解A. 水分制限が必要な患者に十分なエネルギーを投与するため
  2. B. 浸透圧を下げるため
  3. C. 下痢を予防するため
  4. D. 蛋白質を減らすため

解説

高濃度（高エネルギー密度）の栄養剤は、同じエネルギーをより少ない容量で投与できるため、心不全・腎不全・肝硬変など水分制限を要する患者や、投与時間を短縮したい患者に有用。一方で単位容量あたりの水分が減る（1 kcal/mL 製剤で水分約 85%、1.5〜2.0 kcal/mL では 70% 前後）ため、脱水に注意し必要に応じて白湯を追加する。浸透圧はむしろ高くなり、下痢のリスクは上がる方向である。
