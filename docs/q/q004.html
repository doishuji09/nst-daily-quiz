エネルギー代謝

Harris-Benedict の式で算出されるのはどれか。

答えと解説を見る
  1. A. 総エネルギー消費量（TEE）
  2. 正解B. 基礎エネルギー消費量（BEE）
  3. C. 安静時エネルギー消費量（REE）
  4. D. 非蛋白カロリー量

解説

Harris-Benedict の式は身長・体重・年齢・性別から基礎エネルギー消費量（BEE）を推定する式。実際の投与エネルギーは BEE に活動係数（AF）とストレス係数（SF）を掛けて総エネルギー消費量を見積もる。なお同式は欧米人のデータに基づくため日本人ではやや過大評価になりやすく、簡易式（25〜30 kcal/kg/日）や間接熱量測定も併用される。
