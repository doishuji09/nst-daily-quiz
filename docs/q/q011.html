ビタミン

Refeeding syndrome の予防のために、栄養投与の開始前から補充すべきビタミンはどれか。

答えと解説を見る
  1. 正解A. ビタミンB1（チアミン）
  2. B. ビタミンB12
  3. C. ビタミンC
  4. D. ビタミンK

解説

ビタミンB1 は糖代謝（ピルビン酸脱水素酵素の補酵素）に必須で、体内貯蔵量が2〜3週間分と少ない。低栄養状態で糖質を急速に投与するとB1 の需要が跳ね上がり、欠乏すると Wernicke 脳症や乳酸アシドーシス、脚気心（高拍出性心不全）を起こす。そのため refeeding のリスクがある患者では、糖質投与の前からチアミンを補充する。
