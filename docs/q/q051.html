病態別栄養管理

がん悪液質（cancer cachexia）の特徴として、正しいものはどれか。

答えと解説を見る
  1. A. 十分な栄養投与のみで完全に是正できる
  2. 正解B. 炎症を背景に骨格筋量が減少し、通常の栄養療法だけでは改善しにくい
  3. C. 体重は増加する
  4. D. 食欲は保たれる

解説

がん悪液質は、腫瘍や宿主由来の炎症性サイトカインを背景に、食欲不振と代謝異常（蛋白異化亢進、インスリン抵抗性、脂肪分解亢進）が進行し、骨格筋量が減少する多因子性の症候群。単純な飢餓と異なり栄養投与だけでは是正しきれない点が最大の特徴で、栄養療法に加え運動療法、症状緩和、薬物療法を組み合わせた集学的アプローチと、不応性悪液質の段階では QOL を優先した目標設定が求められる。
