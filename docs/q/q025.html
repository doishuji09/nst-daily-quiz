経腸栄養

経腸栄養剤のうち、窒素源がアミノ酸で、脂質含有量が極めて少なく、消化をほとんど必要としないものはどれか。

答えと解説を見る
  1. A. 半消化態栄養剤
  2. B. 消化態栄養剤
  3. 正解C. 成分栄養剤（エレンタール®など）
  4. D. 濃厚流動食

解説

成分栄養剤は窒素源が結晶アミノ酸、脂質は必須脂肪酸を補う程度の極少量で、消化をほとんど要さずほぼ完全に吸収される。短腸症候群、クローン病、重症膵炎、高度の消化吸収障害などが適応。一方で浸透圧が高く下痢を起こしやすい、長期使用で必須脂肪酸欠乏を来しうる、味が良くないという欠点がある。消化態栄養剤の窒素源はアミノ酸＋ジペプチド・トリペプチド、半消化態は蛋白質（カゼインや大豆蛋白）である。
