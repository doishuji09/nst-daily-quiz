静脈栄養

中心静脈カテーテル挿入直後に、呼吸困難と患側呼吸音の減弱が出現した。まず疑うべき合併症はどれか。

答えと解説を見る
  1. 正解A. 気胸
  2. B. 空気塞栓
  3. C. カテーテル先端の位置異常による不整脈
  4. D. 血栓性静脈炎

解説

鎖骨下静脈や内頸静脈の穿刺では胸膜を損傷して気胸を起こすことがあり、挿入直後〜数時間後の呼吸困難、胸痛、患側呼吸音減弱が典型的な所見。挿入後の胸部 X 線は先端位置の確認と同時に気胸の有無を見るためにも必須である。そのほかの早期合併症には動脈穿刺・血腫、空気塞栓、胸管損傷（左側）、不整脈などがある。
