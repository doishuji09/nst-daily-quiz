経腸栄養

経腸栄養開始後に下痢を来した患者への対応として、まず検討すべきでないものはどれか。

答えと解説を見る
  1. A. 投与速度を落とす
  2. B. 栄養剤の温度・濃度・浸透圧を見直す
  3. 正解C. 直ちに経腸栄養を中止して中心静脈栄養へ切り替える
  4. D. 抗菌薬関連下痢症や CD 腸炎など薬剤・感染の要因を除外する

解説

経腸栄養中の下痢の原因は、投与速度が速い、浸透圧が高い、栄養剤が冷たい、脂質が多い、投与ラインの細菌汚染など栄養剤側の要因だけでなく、抗菌薬関連下痢症・Clostridioides difficile 感染、ソルビトールを含む薬剤（液剤）、低アルブミン血症による腸管浮腫など多様。まずは原因を検索し、速度・濃度の調整、半固形化、可溶性食物繊維やプレ／プロバイオティクスの追加などで継続を図る。安易な中止は腸管萎縮を招くため避ける。
