病態別栄養管理

周術期の ERAS（術後回復促進）プロトコルにおける栄養管理の考え方として、適切なものはどれか。

答えと解説を見る
  1. A. 術前は長時間の絶飲食を厳守する
  2. 正解B. 術前2〜3時間前まで清澄水（炭水化物飲料）の摂取を許容し、術後は早期に経口摂取を開始する
  3. C. 術後1週間は絶食とする
  4. D. 術前の栄養評価は不要である

解説

ERAS では、長時間の絶飲食がインスリン抵抗性と異化を助長するという考えから、麻酔導入の2〜3時間前までの清澄水（炭水化物含有飲料）摂取を許容し、術後も可能な限り早期に経口・経腸摂取を再開する。術前の栄養評価と、低栄養例への術前栄養介入（術前免疫栄養を含む）も重要な要素で、これらを束ねることで術後合併症の減少と在院日数の短縮を目指す。
