エネルギー代謝

侵襲時の代謝反応（Moore の分類）で、異化が亢進し尿中窒素排泄が増加する時期はどれか。

答えと解説を見る
  1. 正解A. 第I相（傷害期）
  2. B. 第II相（転換期）
  3. C. 第III相（同化期）
  4. D. 第IV相（脂肪蓄積期）

解説

Moore は手術侵襲後の回復過程を4相に分けた。第I相（傷害期、injury phase）は受傷直後から数日で、カテコラミン・コルチゾール・グルカゴンなどが上昇し、糖新生と蛋白異化が亢進して尿中窒素排泄が増える時期。第II相（転換期）で異化から同化へ切り替わり、第III相（同化期）で蛋白合成が進み、第IV相で脂肪が蓄積する。第I相で無理に高カロリーを投与すると overfeeding になりやすく、この時期は permissive underfeeding が考慮される。
