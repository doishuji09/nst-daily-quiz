栄養サポートチーム加算に関する記述として、正しいものはどれか。

答えと解説を見る
  1. A. すべての入院患者に毎日算定できる
  2. 正解B. 栄養管理計画を策定した患者のうち、一定の要件を満たす患者に週1回算定できる
  3. C. 外来患者のみが対象である
  4. D. 医師の指示があれば研修要件は不要である

解説

栄養サポートチーム加算は、栄養管理計画を策定している入院患者のうち、血清アルブミン値が一定以下、経口摂取または経腸栄養への移行を目的としている、栄養治療により改善が見込まれる、などの要件に該当する患者について、週1回（一部の病棟では月1回など）算定できる。チームの構成員には所定の研修修了などの要件があり、実際の要件は診療報酬改定ごとに見直されるため最新の告示を確認する必要がある。
