NST運営

NST（栄養サポートチーム）の構成員として、中心となる職種の組み合わせとして適切なものはどれか。

答えと解説を見る
  1. 正解A. 医師・看護師・管理栄養士・薬剤師
  2. B. 医師のみ
  3. C. 管理栄養士と調理師
  4. D. 医師と事務職員

解説

NST は医師、看護師、管理栄養士、薬剤師を中核に、臨床検査技師、言語聴覚士、理学療法士、作業療法士、歯科医師、歯科衛生士、社会福祉士などが加わる多職種チーム。栄養サポートチーム加算の算定要件でも、所定の研修を修了した医師・看護師・薬剤師・管理栄養士のうち1名が専任専従であることなどが定められている。職種ごとの視点を持ち寄ること自体がチームの価値である。
