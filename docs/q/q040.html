静脈栄養

PICC（末梢挿入型中心静脈カテーテル）の特徴として、正しいものはどれか。

答えと解説を見る
  1. 正解A. 気胸のリスクが鎖骨下穿刺より低い
  2. B. 高カロリー輸液は投与できない
  3. C. 留置期間は最長でも3日である
  4. D. 上腕から挿入するため中心静脈圧は測定できない

解説

PICC は上腕の尺側皮静脈などから挿入して先端を上大静脈に留置するカテーテルで、胸腔を穿刺しないため気胸・血胸のリスクが低く、動脈誤穿刺時の圧迫止血も容易。中心静脈カテーテルであるため高カロリー輸液の投与も中心静脈圧の測定も可能で、数週間〜数か月の長期留置に向く。一方で静脈血栓症や、細く長いことによる閉塞・輸液速度の制限には注意が要る。
